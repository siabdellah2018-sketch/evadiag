# التقويم التشخيصي — Test diagnostique

تطبيق كامل (يعمل فعليًا، وليس نموذج معاينة) لإدارة الاختبارات التشخيصية:
حسابات ثابتة للتلاميذ، رفع أسئلة PDF، مؤقّت حقيقي، منع اجتياز الاختبار مرتين،
ونتائج يديرها الأستاذ. مجاني بالكامل عبر Vercel + Supabase.

## الخطوات (بالترتيب، بدون أي برمجة مطلوبة منك)

### 1) إنشاء مشروع Supabase (قاعدة البيانات) — مجاني
1. اذهب إلى https://supabase.com وأنشئ حسابًا (بدون بطاقة بنكية)
2. أنشئ مشروعًا جديدًا (New project) — اختر أي اسم وكلمة سر لقاعدة البيانات (احفظها جانبًا)
3. من القائمة الجانبية: SQL Editor > New query
4. افتح ملف `supabase/schema.sql` الموجود في هذا المجلد، انسخ كل محتواه، الصقه، ثم اضغط Run
5. من Settings > API، انسخ ثلاث قيم ستحتاجها لاحقًا:
   - Project URL → ستكون NEXT_PUBLIC_SUPABASE_URL
   - anon public key → ستكون NEXT_PUBLIC_SUPABASE_ANON_KEY
   - service_role key (اضغط Reveal) → ستكون SUPABASE_SERVICE_ROLE_KEY (لا تشاركها مع أحد أبدًا)

### 2) رفع المشروع على GitHub
1. أنشئ حسابًا على https://github.com إن لم يكن لديك
2. أنشئ مستودعًا (repository) جديدًا فارغًا
3. ارفع كل ملفات هذا المجلد إليه (يمكنك استعمال زر "Upload files" في واجهة GitHub مباشرة، بدون أي أوامر)

### 3) الاستضافة على Vercel — مجاني
1. اذهب إلى https://vercel.com وسجّل الدخول بحساب GitHub
2. اضغط "Add New" > "Project" واختر المستودع الذي رفعته
3. قبل الضغط على Deploy، افتح قسم "Environment Variables" وأضف:
   - `NEXT_PUBLIC_SUPABASE_URL` = (القيمة من الخطوة 1)
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = (القيمة من الخطوة 1)
   - `SUPABASE_SERVICE_ROLE_KEY` = (القيمة من الخطوة 1)
   - `TEACHER_ACCESS_CODE` = اختر أنت كلمة سر قوية تستعملها للدخول كأستاذ
4. اضغط Deploy وانتظر دقيقة أو دقيقتين
5. ستحصل على رابط تطبيقك (مثال: `https://your-app.vercel.app`) — هذا هو رابط تطبيقك الدائم والمجاني

## كيف تستعمل التطبيق بعد النشر

1. افتح الرابط > اختر "أستاذ(ة)" > أدخل TEACHER_ACCESS_CODE الذي اخترته
2. في "حسابات التلاميذ": الصق لائحة تلاميذك بالصيغة `الاسم الكامل ; رمز Massar ; كلمة السر` (سطر لكل تلميذ)
3. في "اختبار جديد": ارفع ملف PDF، حدد المدة وعدد الأسئلة والأجوبة الصحيحة، احصل على كود الاختبار
4. شارك كود الاختبار مع تلاميذك — كل تلميذ يدخل بـ: اسمه الكامل + رمز Massar + كلمة سره + كود الاختبار
5. في "النتائج": أدخل كود الاختبار لمتابعة نتائج التلاميذ، وإظهار الأجوبة الصحيحة إن أردت، ومنح محاولة إضافية لأي تلميذ

## حدود يجب معرفتها
- قاعدة بيانات Supabase المجانية تتوقف تلقائيًا (pause) بعد 7 أيام بدون أي نشاط — إعادة التفعيل بضغطة زر واحدة من لوحة Supabase، بدون فقدان أي بيانات
- التحقق من الهوية هنا مبسّط (مناسب لفصل دراسي) وليس بنفس مستوى حماية تطبيقات بنكية — كافٍ تمامًا لهذا الاستعمال
- ملفات PDF تُخزَّن كعامة (public) عبر رابط غير قابل للتخمين — إذا أردت لاحقًا حمايتها بشكل أكثر صرامة يمكن تطويرها
